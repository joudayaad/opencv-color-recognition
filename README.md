# OpenCV Color Recognition

This project detects the orange color in an image using OpenCV.

## Steps

1. Install OpenCV.
2. Upload an image to Google Colab.
3. Read the image using OpenCV.
4. Convert the image from BGR to HSV color space.
5. Define the HSV range for orange.
6. Create a mask to detect orange pixels.
7. Calculate the percentage of orange pixels in the image.
8. Display whether orange color is detected.

## Technologies Used

- Python
- OpenCV
- NumPy
- Google Colab

## Output

The program displays the original image, the color mask, and prints:

`Orange color detected ✅`
